## Issues by priority

### 🔴 API returns empty responses
**Description:** All API endpoints return empty responses causing 'Expecting value: line 1 column 1 (char 0)' JSON parse errors. Users cannot get any stock analysis data.  
**Fix:** Check Vercel deployment and ensure analyze.js function exports handler correctly with proper return statements  
**File:** `analyze.js:handler or vercel.json configuration` ❌

### 🔴 CORS headers missing
**Description:** GitHub Pages frontend cannot access Vercel API due to missing CORS headers. Users see network errors when trying to analyze stocks.  
**Fix:** Add 'Access-Control-Allow-Origin: *' and handle OPTIONS preflight requests in analyze.js  
**File:** `analyze.js:response headers` ❌

### 🟠 Multiple theme toggle buttons conflict
**Description:** Three buttons share .theme-toggle class causing Playwright strict mode violations. Theme toggle functionality may be broken.  
**Fix:** Use unique IDs or classes: .home-btn, .account-btn, .theme-btn instead of shared .theme-toggle class  
**File:** `index.html:button elements` ❌

### 🟠 Add stock button not clickable
**Description:** Landing page elements intercept clicks on Add Stock button. Users cannot add stocks to their portfolio.  
**Fix:** Fix z-index stacking or pointer-events CSS on .lp-stat elements to not block .add-btn clicks  
**File:** `index.html:.lp-stat CSS or .add-btn positioning` ❌

### 🟠 Stock chart not rendering
**Description:** Price charts don't appear after selecting stocks. Users cannot visualize stock price movements and technical analysis.  
**Fix:** Ensure chart library is loaded and chart container is populated with API data in displayAnalysis function  
**File:** `index.html:chart rendering logic` ❌

### 🟠 RSI calculation returns zero
**Description:** RSI indicator calculation is incorrect, returning 0 instead of ~50 for flat prices. Technical analysis will be misleading.  
**Fix:** Fix RSI calculation in calcRSI function to handle edge cases and return proper 0-100 values  
**File:** `analyze.js:calcRSI function` ❌

### 🟡 Missing input validation
**Description:** API doesn't validate required parameters or return proper 400 errors. Invalid requests return 404 instead of meaningful errors.  
**Fix:** Add parameter validation at start of analyze.js handler and return 400 status for missing/invalid symbols  
**File:** `analyze.js:parameter validation` ❌

### 🟡 localStorage cache not working
**Description:** Stock analysis results aren't cached locally. Users experience slower performance on repeated stock lookups.  
**Fix:** Implement caching in fetchAnalysis function to store/retrieve results from localStorage with symbol key  
**File:** `index.html:fetchAnalysis function` ❌

### 🟡 Remove stock button missing
**Description:** Users cannot remove stocks from their portfolio as remove buttons don't exist on stock cards.  
**Fix:** Add .remove-btn elements to stock card template in displayAnalysis or createStockCard function
